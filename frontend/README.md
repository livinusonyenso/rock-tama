# ROCK-TAMA Natural Spring Water: Website

Premium e-commerce and wholesale website for ROCK-TAMA natural spring water from Nanka, Anambra State, Nigeria.

Built with Next.js 16 (App Router), React 19, TypeScript and Tailwind CSS 4.

## Getting started

```bash
npm install
npm run dev        # http://localhost:3000
```

Other scripts:

```bash
npm run lint       # ESLint
npx tsc --noEmit   # type-check
npm run build      # production build
npm run start      # serve the production build
```
